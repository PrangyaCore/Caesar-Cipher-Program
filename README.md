# Caesar-Cipher-Program
"A Python project to encrypt and decrypt messages using Caesar Cipher"
🚀Features:
**Bi-Directional Operations:** Easily switch between **encrypting** plain text into cipher text and **decrypting** secret messages back to readable text.
**Preserves Formatting:** Automatically handles uppercase and lowercase letters while leaving spaces, numbers, and special punctuation untouched.
**Continuous Execution Loop:** Features a built-in interactive loop allowing you to process multiple messages in a single session without restarting the program.
**Error Handling:** Built-in safeguards to catch invalid entries (such as text entered instead of numbers for shift values) and keep the program running smoothly.

---

💻 Built With

* **Python 3.13** 
* **IDLE** (Development Environment)

---

 📋 How to Run the Program

1. Ensure you have **Python 3.x** installed on your computer.
2. Download or copy the `caesar.py` file into your workspace.
3. Open your Python **IDLE**, go to **File > Open**, and select your `caesar.py` file.
4. Press **F5** on your keyboard to run the module.
5. Follow the on-screen prompts to input your message, choose your shift value, and select whether you want to encrypt or decrypt!
